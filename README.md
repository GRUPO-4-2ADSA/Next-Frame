# Next Frame

> Sistema de apoio à decisão para produtoras cinematográficas.

## Sobre o projeto

O Next Frame é um sistema desenvolvido para auxiliar produtoras cinematográficas na tomada de decisões sobre novos projetos.

A plataforma utiliza dados históricos de filmes para realizar análises, comparações e gerar indicadores que auxiliam na avaliação de riscos financeiros antes de um investimento.

## Objetivo

Reduzir decisões baseadas apenas em expectativas, fornecendo dados históricos que permitam uma análise mais fundamentada sobre o potencial de um projeto cinematográfico.

## Funcionalidades

- Cadastro e login de usuários
- Cadastro e gerenciamento de produtoras
- Cadastro de projetos cinematográficos
- Busca e comparação com filmes históricos
- Dashboard com indicadores
- Ranking dos maiores sucessos
- Análise de rentabilidade
- Análise de avaliações
- Geração de relatórios em PDF

## Análises

A partir das características de um projeto, o sistema utiliza a base histórica de filmes para apresentar informações como:

- Média de orçamento
- Média de receita
- ROI aproximado
- Avaliação média
- Popularidade
- Quantidade de filmes que recuperaram o investimento
- Filmes semelhantes
